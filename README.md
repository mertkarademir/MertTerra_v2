# Photo Blog

A simple photo blog application that allows you to organize and display your photos in folders with descriptions.

## Features

- Create main folders and subfolders for organizing photos
- Upload multiple photos at once
- Add descriptions to your photos
- Responsive grid layout for photo display
- Modern and clean user interface

## How to Use

1. Open `index.html` in your web browser
2. Create folders:
   - Click "New Folder" to create a main folder
   - Click "New Subfolder" to create a subfolder within the currently selected folder
3. Upload photos:
   - Select a folder
   - Click "Choose Files" to select photos from your computer
   - Click "Upload Photos" to add them to the selected folder
4. Add descriptions:
   - Click on any photo to add or edit its description
   - Enter your description in the modal that appears
   - Click "Save" to update the description

## Folder Structure

The application uses a hierarchical folder structure:
- Main folders (e.g., "Mushrooms")
- Subfolders (e.g., "Amanita Muscaria" within "Mushrooms")

## Notes

- Photos are stored locally in your browser
- The application uses modern web technologies and requires a modern browser
- All data is stored in the browser's memory and will be cleared when you close the browser
